# BetterAmongUs

A client-side Among Us mod.

## Changes

- Added VanillaEnhancements-style dark mode for chat, meetings, HUD controls, notifications, the task tracker, and the friends list.
- Removed BetterAmongUs chat censoring. Messages remain visible after the game starts and after meetings end.
- Kept the normal Among Us chat restrictions. Players still cannot chat when they are not allowed to.
- Preserved BetterAmongUs meeting role, name, and player information displays.

## Installation

1. Download the appropriate release from the [Releases](https://github.com/scrawlyy/BetterAmongUs/releases) page.
2. Extract the files into the Among Us installation folder.
3. Replace the existing files when updating.
